# 税务业务管理系统 UI 优化记录

- 版本：V1.1
- 日期：2026-11-01
- 技术栈：Servlet 4 + JSP 2.3 + JSTL + Bootstrap 5.3 + Chart.js 4 + 原生 JavaScript
- 设计参考：用户提供的 Ant Design Pro Analysis Dashboard 截图

## 1. 改造范围

本次改造保留原有 MVC、JDBC、API、数据库和权限体系，只调整 JSP 视图、公共布局、CSS/JavaScript 与 Dashboard 的图表数据序列化。

1. 建立统一设计变量：页面背景、白色内容面板、蓝色强调色、文字层级、边框、间距、圆角和轻量阴影。
2. 公共框架改为浅色侧栏与白色顶栏；侧栏菜单按业务分组，支持展开/收起；移动端支持遮罩式抽屉导航。
3. Dashboard 改为四列核心指标、趋势/金额切换、申报类型金额排名、最近申报和申报状态占比。
4. 业务列表统一为“页面标题 - 筛选条件 - 数据表格 - 分页”结构；表格、状态标签、按钮和数字列统一规范。
5. 业务表单统一为分组面板与底部白色操作栏；详情页统一为信息摘要、流程时间线和模板字段表格。
6. 登录页参考 `https://v8.chaoxing.com/` 的公开登录页，采用左侧品牌插画、右侧白色登录区、紫色页签与主按钮；测试账号收纳为登录按钮下方的一行紧凑标签。
7. 403、404、500 错误页同步使用统一颜色、卡片和操作按钮规范。

## 3. Dashboard 数据口径

Dashboard 不包含前端静态演示数组，也没有虚构同比、环比：

- 申报总量、待审核、审核通过、金额合计、状态分布和类型金额均来自 `StatisticsService.summary()`。
- 数据范围沿用原规则：管理员、审核员和分析员查看全局；经办员和只读用户只看本人创建的申报。
- 趋势图近 6 个月数量与金额均来自 `MonthlyPoint`。
- 图表“申报数量 / 申报金额”切换会实际切换 Chart.js 数据集和纵轴单位。
- 类型金额排名来自真实 `TypeAmount` 聚合结果。
- 状态占比来自真实 `StatusCount` 聚合结果。
- 金额单位明确标注为“元”，并注明为课程演示模拟金额。

为趋势图增加月度金额序列的改动仅位于 `DashboardServlet.buildChart()`，没有修改 Service、DAO、表结构或业务状态机。

## 4. 登录页与快捷测试

登录页同时参考用户提供的 `E:\2026-2\Java EE\login.jsp` 与 `https://v8.chaoxing.com/` 的实际页面结构。通过 Chromium 实测参考页在 `1440 × 900` 下的主卡片约为 `1260 × 882`，输入框高 48px，主按钮颜色为 `rgb(112, 108, 232)`。

实现没有复制参考站点的品牌素材或脚本，只沿用左右分栏、深蓝标题、浅灰插画区、紫色交互色和大尺寸输入框等视觉语言；插画使用为本项目创建的本地上税业务 SVG。为避免参考页在较高屏幕下出现大面积内部空白，最终将登录容器压缩为 `1160 × 760`，保留左右比例并收紧底部空间。

五个可用测试角色收纳在登录按钮下方的单行小标签中，不占用额外的大块页面空间：

| 角色 | 账号 |
| --- | --- |
| 系统管理员 | `admin / Admin@123` |
| 申报经办员 | `clerk1 / Clerk@123` |
| 申报审核员 | `reviewer1 / Reviewer@123` |
| 统计分析员 | `analyst1 / Analyst@123` |
| 只读访客 | `viewer1 / Viewer@123` |

点击标签后由 `login.js` 填入账号密码并提交原有登录表单。完整账号密码写在标签的 `title` 与无障碍名称中。CSRF Token、账号状态、密码校验和权限加载流程均未绕过。

## 6. 保留与限制

- 未引入 React、Vue 或新的前端依赖。
- 未修改数据库结构、接口路径、权限规则和申报/审核状态机。
- Dashboard 当前接口固定展示近 6 个月，因此没有添加无后端参数支持的“今日 / 本周 / 本月”快捷筛选或自定义日期范围。
- 未展示同比和环比，因为现有接口没有可靠的同期对比数据。
- 登录快捷账号适用于演示环境；正式部署应删除测试账号入口或由服务端配置控制显示。
