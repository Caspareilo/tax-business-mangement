## 来源 1：Element Plus —— Table 组件文档

- URL：https://element-plus.org/en-US/component/table.html
- 抓取结果：HTTP 200，页面正文约 1.0 MB。
- 实际观察到的模式：
  - 表格通过 `el-table` + `el-table-column` 声明列；`fixed` 支持 `true` / `'left'` / `'right'`，文档示例把操作列固定在右侧（`<el-table-column fixed="right" label="Operations" min-width="120">`）。
  - 大数据量时使用固定表头（`height`/`max-height`）；列排序使用 `sortable`，是否远程排序由 `sort-change` 等事件处理。
  - loading 与空数据是表格的一等状态，而不是页面级兜底。
  - 操作按钮使用 `el-button link type="primary" size="small"`，行内操作保持轻量。
- 本项目应用：
  - 所有列表页使用 `el-table`，操作列 `fixed="right"`，长表格使用分页而非无限滚动。
  - 表格显式绑定 `v-loading`、空状态插槽、错误提示条；不使用假数据占位。
  - 排序由后端白名单字段完成，前端只发排序参数，不本地排序整页数据。

## 来源 2：Element Plus —— Form 组件文档

- URL：https://element-plus.org/en-US/component/form.html
- 抓取结果：HTTP 200，页面正文约 0.6 MB。
- 实际观察到的模式：
  - `el-form` 以 `:model` 提供数据对象，`el-form-item` 作为每个字段容器；`label-width="auto"` 是常见做法。
  - 筛选区使用 `:inline="true"` 的行内表单，与表格上下组合。
  - 校验通过 `rules` 定义，`el-form-item` 负责展示错误反馈。
- 本项目应用：
  - 列表页筛选区用 `el-form inline` + 查询/重置按钮；表单页用独立页面 + 分组表单 + 底部固定操作区。
  - 必填项由前端规则与后端 Jakarta Validation 双重校验，错误以后端返回为准展示。
  - 表单字段标签、必填标识、帮助文本统一由字段配置渲染。

## 来源 3：Ant Design —— Data Display 设计规范

- URL：https://ant.design/docs/spec/data-display
- 抓取结果：HTTP 200。
- 实际观察到的模式：
  - 文档强调"数据展示要帮助用户快速定位与浏览"，并特别提示极端情况（内容过长、初始为空）需要设计。
  - 表格应与其他界面元素（排序、搜索、筛选、分页）配合使用。
  - 表格中的时间、状态、操作栏应保持文字完整不换行；空单元格用 `-` 表示无数据。
  - 状态类信息需要文本，而非仅靠颜色。
- 本项目应用：
  - 列表页默认"筛选 → 表格 → 分页"结构；空单元格显示 `-`。
  - 状态列使用"文本 + 低饱和色标签"组合，颜色只做辅助。
  - 空数据、加载、错误、无权限四态分别实现，并给出可执行动作（重置筛选、重试、返回）。

## 来源 4：Vue Vben Admin 5.0 官方文档

- URL：https://doc.vben.pro/en/guide/introduction/vben.html
- 抓取结果：HTTP 200。
- 实际观察到的模式：
  - 官方定位为 Vue 3 + Vite + TypeScript 的中大型后台方案，明确列出"动态菜单""按钮级权限校验""多主题"等能力。
  - 文档导航包含 Routing and Menu、Access Control 等章节，说明其信息架构为：侧边导航 + 权限驱动的路由/菜单。
  - 强调工程化与组件二次封装，而非单一页面模板。
- 本项目应用：
  - 采用"侧边导航 + 顶部栏 + 面包屑 + 页面标题"的后台信息架构。
  - 菜单由后端返回的菜单权限动态生成；路由守卫只做体验层拦截，后端 `@PreAuthorize` 才是安全边界。
  - 不引入 Vben 的 Monorepo、主题切换、国际化等重型能力，保持课程项目可维护性。

## 采用的设计决策

1. 布局：左侧固定导航（220–248px，可折叠），顶部栏显示系统名、当前用户与角色，内容区统一间距。
2. 视觉：白/浅暖灰背景，白色内容卡片，深灰正文，中性灰辅助文字；主色低饱和蓝灰 `#526B7A`，墨绿仅少量用于成功态。
3. 数据页结构：标题与主操作 → 筛选区 → 表格 → 分页；表格具备加载、空、错误状态。
4. 表单：独立页面、字段分组、必填标识、前端即时校验 + 后端权威校验。
5. 状态表达：文本 + 克制的状态色，不允许只靠颜色。
6. 图表：仅展示有业务含义的指标（月度趋势、状态分布、类型金额），标题标注统计口径。

## 明确不采用

- 不采用大面积紫色/亮蓝渐变、玻璃拟态、发光边框、悬浮营销卡片。
- 不采用 Vben 的完整模板与品牌素材，不复制任何 Logo 或商业图标。
- 不采用拖拽式表单设计器（V1.0 仅做字段配置 + 预览）。
- 不采用前端本地排序/过滤来伪造分页与统计结果。
- 不采用无限滚动替代分页。
