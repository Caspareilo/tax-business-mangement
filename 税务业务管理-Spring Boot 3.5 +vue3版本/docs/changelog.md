# 变更记录

## [1.3.0] - 2026-11-03

### 登录页自助注册

- 登录页新增“注册账号”页签，与“账号登录”“角色说明”在桌面和手机端保持一行等宽对齐。
- 移除登录按钮下方重复的注册提示。
- 新增 `POST /api/v1/auth/register` 和 `RegisterRequest`，允许匿名注册。
- 服务端校验账号格式、显示名称、密码强度、确认密码和账号重复。
- 注册事务创建账号并固定分配 `VIEWER` 角色，不接受客户端提交角色。
- 注册成功后返回登录页并预填账号。
- 登录页注册模式压缩垂直间距，页脚保持在卡片内，不产生横向或纵向溢出。

### 验证

- 后端集成测试增至 28 个，全部通过。
- Vue TypeScript 构建和 ESLint 通过。
- Docker 前端镜像已重建，登录与注册界面完成桌面、手机截图检查。

### 决策与假设

- 使用会话 Cookie 而非 JWT：课程项目无需分布式会话，便于演示 401/403 与注销。
- 动态表单值存 `tax_declaration.form_data` JSON；查询用稳定字段 + 快照，避免复杂 JSON 查询。
- “有效申报唯一”由服务层事务校验 + 索引查询实现；MySQL 条件唯一索引无法覆盖多状态组合。
- 演示密码统一 `Demo@1234`，仅存 BCrypt；种子数据全部虚构。
- 测试库与开发库分离，测试启动会清空 `tax_business_test`。
- 前端 ESLint/Prettier 在功能完成后补充，并对模板内联多语句事件做重构以通过解析。

### 修复（开发与验收过程中）

- 同一测试事务内 MyBatis 一级缓存导致提交校验读取旧 `form_data`：新增 `selectFreshById`（`useCache=false`、`flushCache=true`）用于提交前读取。
- 审核历史 VO 字段为 `action`，修正测试断言。
- 表单模板分页参数与后端不一致：前端统一使用 `declarationTypeId`。
- 趋势图图例与右轴名称重叠：图例居中。
- 1366×768 申报/审核表格金额列被固定操作列遮挡：精简非关键列、调整列宽。
- 动态表单长标签换行、单选选项拥挤：标签宽度 150px，单选独占整行。
- 期间列日期换行：`.period-text` 不换行。
- 工作台“审核通过率”卡片改为“审核通过 / 已退回”合计展示；类型图表改为模拟金额口径，与统计页一致。
- 统计分析新增近 6/12 个月趋势范围选择，重置恢复近 6 个月。
- 页面底色由浅暖灰改为白色，卡片继续使用描边区分层级；表头、悬浮、边框等辅助色由暖灰统一调整为中性灰白，避免米白观感。
- Prettier 格式化将模板内联多语句事件拆行导致 Vue 编译失败：抽取 `resetQuery` 等方法。
